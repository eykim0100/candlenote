# 캔들노트

큰 움직임이 있었던 날의 뉴스와 공시를 캔들 위에서 바로 보는 주식 차트예요.

- 화면: `index.html` (GitHub Pages로 게시)
- 데이터: `data/kr/` (평일 오후 2시쯤 GitHub Actions가 자동으로 갱신)
- 수집 프로그램: `scripts/collect_kr.py`
- 직접 쓴 기업 설명: `data/kr_notes.json` (종목코드별 업종·설명·주요 제품·매출 구성)

데이터 출처: 금융위원회 주식시세정보(공공데이터포털), 금융감독원 DART, 네이버 뉴스 검색(NAVER API HUB).
투자 권유가 아니에요.
